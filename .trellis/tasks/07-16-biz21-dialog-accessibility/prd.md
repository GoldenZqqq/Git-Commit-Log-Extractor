# BIZ-21 加固弹层菜单可访问性

## Goal

系统加固主要弹层、菜单和分裂按钮的键盘关闭、焦点管理、ARIA 语义与外部点击行为。

## Requirements

- 建立可复用的 dialog/menu 焦点与关闭行为，避免每个组件各自实现不一致。
- 模态弹层打开后焦点进入，Tab 不逃逸；关闭后焦点回到触发按钮。
- 非模态菜单支持 Escape、外部点击、方向键或符合其角色的键盘导航。
- 图标按钮、菜单项、错误提示和动态状态具备正确名称/role。

## Acceptance Criteria

- [ ] 设置、批量、补写、自定义周期和仓库编辑弹层可全键盘操作。
- [ ] AI/导出/复制分裂菜单支持 Escape 与焦点回收。
- [ ] 主要弹层通过自动化 axe 扫描且无严重违规。
- [ ] Playwright 覆盖焦点进入、Tab、Escape、关闭后回焦。

## Evidence

- 当前部分组件已有 Escape/外部点击逻辑，但分散在各组件，历史 UX 评审明确指出焦点与关闭行为不一致。
