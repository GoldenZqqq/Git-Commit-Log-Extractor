# 官网品牌 3D 场景与交互升级

## Goal

让 GitPulse 官网首屏从“视频背景 + 文案”升级为具有品牌识别度的轻量 3D 场景，提升停留意愿和记忆点，同时保持产品的安静、可靠、本地优先定位，不牺牲首屏加载性能、移动端可用性或无障碍体验。

## Background / Confirmed Facts

- 官网是独立 Astro 站点，入口组件为 `site/src/components/HomePage.astro`。
- 当前首屏在 `site/src/components/HomePage.astro:135` 使用全屏自动播放 MP4，GSAP/ScrollTrigger 逻辑位于 `site/src/scripts/site-motion.ts:35`。
- 官网已有 GitPulse 演示视频、工作流滚动叙事、双语页面和现成的响应式/减少动效处理。
- `site/package.json` 当前没有 Three.js 依赖。
- LOGO 的主要视觉元素是圆环、Git 节点连接结构、青色节点和橙色脉冲波形。
- Blender MCP 当前可用，能够脚本创建场景、材质、灯光并导出资产。
- `PRODUCT.md` 将 GitPulse 定义为安静、可靠、可信赖的本地工作台，反对无目的的装饰和隐藏主操作。

## Requirements

- R1. 首屏使用一个全屏 3D Canvas 作为品牌场景，模型偏右、文案和主要 CTA 位于左侧覆盖层；不得将模型放进装饰性卡片或单独的媒体卡片中。
- R2. 3D 主体必须可辨识地继承 LOGO 结构：开口圆环、Git 节点网络、青色节点和橙色脉冲波形；模型应采用可控的 Blender 几何建模，避免图片转模型造成 LOGO 变形。
- R3. 视觉风格采用石墨黑、陶瓷白、青色和橙色的精密仪器/工作台方向，避免赛博朋克、霓虹游戏场景和通用 SaaS 插画套路。
- R4. 支持轻量互动：待机悬浮/脉冲、指针视差、有限拖拽查看、节点悬停反馈和点击触发一次完整脉冲；互动不得遮挡导航、标题或 CTA。
- R5. 首屏 3D 场景替换现有首屏自动播放视频；演示视频保留在后续演示区，避免首屏同时加载两套重媒体。
- R6. 对 `prefers-reduced-motion`、WebGL 不可用、移动端和低性能设备提供静态海报或低复杂度降级路径；内容和 CTA 在 Canvas 失败时仍完整可见。
- R7. Three.js 场景使用轻量 GLB 资产、受控设备像素比、视口外暂停/延迟初始化和必要的资源释放；首期模型目标体积控制在约 1–1.5 MB 内，具体以构建和网络预算验证为准。
- R8. 保留中英文页面、语义标题、键盘焦点、对比度和现有响应式行为；3D 仅作为装饰和品牌表达，不承担唯一信息传递。
- R9. 通过 Astro 生产构建、桌面/移动截图、Canvas 非空检查、减少动效检查和 WebGL 降级检查验证。
- R10. 首期范围仅包含首屏 3D 场景；现有工作流滚动章节和演示区不做 3D 联动或结构性重做。

## Acceptance Criteria

- [x] 首屏在支持 WebGL 的桌面浏览器中显示可辨识的 Pulse Core 3D 模型，模型、标题、CTA 和导航无重叠。
- [x] 模型结构明确包含 LOGO 的圆环、节点网络和脉冲波形，青色/橙色材质在首屏对比度下可识别。
- [x] 指针移动、有限拖拽、节点悬停和点击脉冲均可工作，交互不会导致页面布局抖动或滚动锁死。
- [x] 移动端首屏保持可读，Canvas 不横向溢出；低性能/WebGL 失败时静态回退仍显示完整首屏内容。
- [x] `prefers-reduced-motion: reduce` 下不运行持续旋转、视差和脉冲动画，静态模型或海报仍可见。
- [x] 首屏不再同时加载自动播放背景视频；后续演示视频仍可播放。
- [x] 官网 Astro 生产构建通过，既有双语路由、SEO 元数据和现有官网 E2E/响应式检查不回归。
- [x] 任务完成前记录 GLB 大小、首屏资源加载策略和最终验证命令/结果。

## Out of Scope

- 不改 GitPulse 桌面端 React/Tauri 工作台功能。
- 不把真实 Git 提交数据接入官网 3D 场景，不新增后端、埋点或远程 API。
- 不制作完整可编辑的 3D 产品展示器、材质切换器或游戏化场景。
- 不在首期同时重做官网全部版式、文案架构或品牌字体系统。
- 不让 3D 场景跨章节持续渲染或联动现有工作流滚动叙事。

## Notes

- 用户已确认首期采用“仅升级首屏，保持现有工作流/演示区不变”的范围。
- 本 PRD 的文件/行号锚点以当前主分支结构为准，实施时若入口文件移动需同步更新。
