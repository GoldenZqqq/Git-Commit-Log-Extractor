# BIZ-20 仓库搜索与批量操作

## Goal

降低多仓库场景筛选成本，为仓库索引增加搜索、状态筛选和对当前结果的批量启用/禁用。

## Background

- 当前仓库辅助面板直接遍历全部 `repos`，仓库多时只能逐项查找和切换。
- 仓库显示名已统一通过 `resolveRepoDisplayName` 解析精确/通配项目映射，搜索必须复用同一名称语义。
- `settings.disabledRepos` 是生成范围的唯一持久化来源；BIZ-13 的健康结果只是内存投影，批量操作必须同步两者。
- 历史 UX 评审明确提出仓库搜索、批量启停和已启用/禁用筛选；“最近活跃排序”缺少可靠数据源，不纳入本任务。

## Requirements

- 搜索采用去首尾空白、忽略大小写的子串匹配，同时覆盖仓库原名、映射项目名、路径和缓存分支。
- 支持查看全部/已启用/已禁用；状态入口显示各自数量，工具栏显示当前命中数/索引总数。
- “启用当前结果”“禁用当前结果”只作用于当前搜索与状态筛选的可见集合；没有实际可变更仓库时禁用对应按钮。
- 批量更新一次性写入 `settings.disabledRepos`，保留未命中仓库和陈旧禁用路径，并同步健康视图内存投影与报告生成范围。
- 批量操作可逆且不弹确认框；完成后给出包含动作和仓库数量的中文反馈。
- 保持逐项开关、项目映射编辑、重新扫描和空索引引导行为。
- 搜索无结果时提供清除/重置入口；全部仓库禁用时明确提示生成范围为 0，并引导查看已禁用仓库后批量恢复。

## Acceptance Criteria

- [x] 搜索能按原名、映射名、路径和分支命中，并与全部/已启用/已禁用筛选正确组合。
- [x] 批量启用/禁用只修改当前可见集合，未命中仓库和陈旧禁用路径保持不变。
- [x] 批量操作后仓库行、辅助 tab 计数、生成范围、localStorage 与健康视图投影立即同步。
- [x] 搜索空结果与全禁用状态有清晰提示、键盘可用的清除/查看/恢复操作。
- [x] Playwright 覆盖搜索、筛选、批量禁用、批量恢复和全禁用恢复路径；生产构建与完整回归通过。

## Evidence

- 当前 `Workbench` 仓库索引直接遍历全部 `repos`，只有逐项 checkbox。
- 历史 UX 评审会话 `019f3a2f-531a-7920-a449-2d6038797ce9` 已把 repo 搜索/批量启停列为多仓库效率缺口。

## Out of Scope

- 不新增最近活跃排序、提交时间读取、标签/收藏或跨会话持久化筛选条件。
- 不新增 Rust 命令，不改变仓库扫描结果或 `RepoIndexCache` schema。
- 不在本任务把仓库辅助面板扩展成独立全屏管理页；BIZ-23 再处理窄屏/高缩放结构。
