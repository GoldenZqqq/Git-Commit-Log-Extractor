# 加固升级迁移与恢复路径

## Goal

覆盖 v0.5.1 到 v0.5.3 设置、报告历史、配置方案迁移及损坏恢复

## Requirements

- R1：覆盖 v0.5.1 localStorage 报告历史到 v0.5.3 Tauri 文件存储迁移。
- R2：覆盖设置默认值、配置方案 schema、损坏主文件、备份恢复、部分写入和容量边界。
- R3：迁移失败必须保留可用旧数据并显示可操作错误，不静默丢失。
- R4：迁移具有幂等性，重复启动不产生重复历史。

## Acceptance Criteria

- [x] AC1：版本升级、重复迁移、损坏恢复和写入失败均有自动化测试。
- [x] AC2：测试证明用户报告、设置和安全凭据引用不会被错误覆盖。
- [x] AC3：前端、Rust 与 Tauri smoke 门禁通过。

## Dependency

- 依赖发布治理任务建立稳定 v0.5.3 基线。
