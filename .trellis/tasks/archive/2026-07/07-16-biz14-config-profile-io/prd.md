# BIZ-14 配置方案导入导出

## Goal

支持导出和导入脱敏的 GitPulse 配置方案，让团队或多设备复用作者别名、项目映射、证据链接和报告模板。

## Background

- 当前仅支持项目映射 Excel 导入与模板导出。
- `settingsForPersistence` 服务于本机持久化，不是可共享配置协议，包含本机状态与连接配置，不能直接复用。
- 设置页已经使用 Tauri 文件对话框；文件内容读写应继续留在 Rust 命令中。

## Requirements

- 定义带 `schemaVersion: 1` 的 JSON 配置包，并对根字段与配置字段执行严格白名单校验。
- 允许共享项目映射、作者别名、证据链接、报告格式模板、系统提示词模板及直接相关的报告展示选项。
- 永不导出 API Key、OAuth token、代理配置/密码、作者筛选、绝对工作区/输出路径、禁用仓库和报告历史正文。
- 导入前展示规则与模板摘要，用户可选择“合并”或“替换”后再应用，也可取消且不修改设置。
- 合并模式按规则键合并项目映射、作者别名与证据链接，导入值覆盖同键冲突并保留本地其他规则；模板与标量设置使用导入值。
- 替换模式完整替换配置包白名单内的共享字段，不影响白名单外的本机设置与安全凭据。
- 对未知版本、缺失字段、非法字段、类型错误、超大文件和损坏 JSON 给出明确错误，不污染现有设置。

## Acceptance Criteria

- [x] 导出文件包含映射、别名、证据规则和模板，不含任何密钥、OAuth、代理或本机敏感路径。
- [x] 导入支持预览、合并与替换，取消不修改设置。
- [x] 同版本导出后再替换导入，可共享配置保持一致；合并模式保留未冲突的本地规则。
- [x] 旧/未知版本、未知字段、损坏 JSON 和超大文件均有明确错误且不修改设置。
- [x] Rust 文件桥接有大小限制与单元测试，Playwright 覆盖导出白名单、导入预览、合并、替换、取消和非法包路径。

## Out Of Scope

- 不导入导出仓库路径、报告历史、AI 账号、API Key、OAuth token 或代理配置。
- 不引入云同步、自动备份或跨版本迁移框架；当前只接受 `schemaVersion: 1`。
- 不替代现有项目映射 Excel 工作流。
