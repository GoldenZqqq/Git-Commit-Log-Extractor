# BIZ-15 增加项目回顾视图

## Goal

提供项目维度回顾视图，聚合某个项目近期报告、提交统计、证据编号与导出记录，形成可持续复盘资产。

## Requirements

- 从历史记录派生项目列表与时间范围，不重新扫描全部 Git。
- 项目回顾展示报告时间线、报告类型、提交数、AI/导出状态和可追溯证据摘要。
- 项目识别复用项目映射规则；旧历史缺少结构化项目字段时提供兼容回退。
- 支持打开原报告，并提供空态与时间筛选。

## Acceptance Criteria

- [ ] 用户选择项目后能看到该项目相关历史时间线与汇总指标。
- [ ] 项目映射名称一致，同名/旧历史回退规则可预测。
- [ ] 点击条目沿用现有历史打开行为。
- [ ] 无历史、单项目、多项目和旧数据有自动化覆盖。

## Dependency

- 在 BIZ-26 统一报告历史存储后实施，避免先围绕 localStorage 建新读取层。
