# BIZ-20 仓库搜索与批量操作

## Goal

降低多仓库场景筛选成本，为仓库索引增加搜索、状态筛选和对当前结果的批量启用/禁用。

## Requirements

- 支持按仓库名、映射项目名、路径和分支搜索。
- 支持查看全部/已启用/已禁用，并显示命中数。
- “启用当前结果”“禁用当前结果”只作用于当前搜索/筛选集合，并提供结果反馈。
- 保持单仓库切换与项目映射编辑行为。

## Acceptance Criteria

- [ ] 搜索和状态筛选组合正确，不修改未命中的仓库。
- [ ] 批量启用/禁用当前结果后生成范围立即同步。
- [ ] 空结果与全禁用状态有清晰提示和恢复操作。
- [ ] Playwright 覆盖搜索、筛选、批量禁用和批量恢复。

## Evidence

- 当前 `Workbench` 仓库索引直接遍历全部 `repos`，只有逐项 checkbox。
- 历史 UX 评审会话 `019f3a2f-531a-7920-a449-2d6038797ce9` 已把 repo 搜索/批量启停列为多仓库效率缺口。
