# BIZ-23 响应式与高缩放硬化

## Goal

保证 GitPulse 在 320px 宽、200% 缩放和小高度桌面窗口下仍可完成生成、设置、预览与导出主路径。

## Requirements

- 审计并修复工作台头部、报告工具栏、辅助栏、设置、批量和补写弹层的溢出与重叠。
- 关键按钮不得仅靠横向滚动发现；允许内容区域合理滚动。
- 保持桌面密度，不把正常宽度界面退化为移动网页。
- 增加 320px 宽、窄高窗口和 200% 等效 viewport 截图/布局断言。

## Acceptance Criteria

- [ ] 320px 宽及小高度窗口主路径控件无重叠、截断或不可达。
- [ ] 设置与主要弹层在窄屏可滚动且关闭按钮始终可达。
- [ ] 200% 缩放等效视口下可生成、复制和打开设置。
- [ ] Playwright 截图与关键 bounding-box 断言稳定通过。

## Evidence

- 现有响应式断点主要为 720/760/900/980/1040px，没有 320px/高缩放自动化门禁。
