# BIZ-22 拆分任务忙碌状态

## Goal

区分阻塞型任务与轻量操作，使复制、导出、AI 操作等不会不必要地遮挡当前报告或禁用无关控件。

## Requirements

- 用显式任务类型替代单一全局 `isBusy` 语义，至少区分仓库扫描、报告生成、AI 润色、导出和轻量交互。
- 只有会改变报告主体且无法并行的操作可以遮挡预览；导出、复制、轻量设置保存应保留现有预览。
- 同一资源上的冲突操作仍需禁用，避免重复生成、重复导出或状态覆盖。
- 进度文案、取消扫描和按钮 loading 必须绑定正确任务类型。

## Acceptance Criteria

- [ ] 报告生成时仍显示阻塞进度；导出/AI 润色时原预览保持可见。
- [ ] 无关按钮不会因其他轻量操作被全局禁用。
- [ ] 冲突操作仍受到可靠防重保护。
- [ ] Playwright 覆盖至少一个阻塞任务和两个轻量任务状态。

## Evidence

- `src/App.tsx` 当前只有一个 `isBusy`。
- `src/components/Workbench.tsx` 在 `isBusy` 时整块替换 `MarkdownPreview`。
