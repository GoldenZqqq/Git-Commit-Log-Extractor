# BIZ-13 增加工作区健康视图

## Goal

提供集中式工作区健康视图，让用户看到索引新鲜度、失效仓库、禁用仓库、分支状态和可执行修复入口。

## Requirements

- 展示根目录、最近扫描时间、索引仓库数、启用/禁用数和失效路径数。
- 校验缓存仓库路径与 Git 标记是否仍有效，并区分移动/删除、不可访问和分支未知。
- 提供重新扫描、禁用/启用、移除失效缓存项和打开设置等操作。
- 健康检查本地执行，不读取 commit 内容、不触发 AI。

## Acceptance Criteria

- [ ] 用户能在一个视图看到扫描时间及健康汇总。
- [ ] 失效仓库和未知分支明确列出并带修复操作。
- [ ] 修复后工作台仓库索引和生成范围同步更新。
- [ ] 空工作区、全部健康、部分失效三种状态有自动化覆盖。

## Evidence

- `RepoIndexCache` 已保存 `scannedAt`，但 UI 只提示载入缓存数量。
- Rust 扫描会静默跳过失效根目录，没有返回健康诊断模型。

## Dependency

- 在 BIZ-25 扫描循环保护完成后实施。
