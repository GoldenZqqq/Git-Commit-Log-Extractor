# 报告日历接入洞察

## Goal

在 **洞察（Insights）** 视图中新增「报告日历」模块，以月历方式呈现用户本地历史报告（日报 / 周报 / 月报 / 自定义 / 空白日补写），支持点击回看已有报告。与提交热力图形成双轴叙事：

- **提交热力图**：你写了多少代码  
- **报告日历**：你产出了多少报告  

本任务先完成规划收敛与 PRD；实现阶段另经 `task.py start` 批准后进行。

## Background

- 侧栏「最近」已有线性历史列表（筛选 / 搜索 / 打开 / 复制）。
- 洞察已有提交热力图、工作节奏、趋势，缺「报告交付时间线」的可视化。
- 历史数据来源：`ReportHistoryEntry`（localStorage），当前上限 `REPORT_HISTORY_LIMIT = 30`（写死，用户不可配）。
- 已有「清空历史」能力（工作台历史区）；设置页仅有说明文案，保留条数不可调。
- 空白日补写已写入历史，标题 `空白日补写 · {date}`，`periodLabel` 含 `补写草稿`。

## Product Naming

| 用语 | 定义 |
|------|------|
| **报告日历（Report Calendar）** | 以月视图展示本地报告产出记录的洞察模块 |
| **日历落点日（Anchor Day）** | 报告在日历上占据的日期格子 |
| **补写标记** | 空白日补写类历史，与普通日报视觉区分 |

避免：考勤日历、打卡、团队排期（本功能不做）。

## Scope — MVP

### In Scope

1. **入口位置**：洞察 Tab 内独立区块，**已定：置于提交热力图正下方**（热力图与 bottom-grid 之间），标题「报告日历」。
2. **月视图**：
   - 显示当前月份网格；**周起始固定周一**（不跟随系统 locale）。
   - 支持上月 / 下月切换；可选「回到本月」。
   - **周起始已定：固定周一**（不随系统 locale）。
3. **格子标记**（有报告的日期）：
   - 日报（含普通生成）
   - 空白日补写（与日报区分色/角标）
   - 周报落点
   - 月报落点
   - 自定义报告落点
   - 同一天多份报告：叠加圆点或数字角标
4. **落点规则（已定草案）**：
   - **日报 / 补写**：`range.startDate`（单日）
   - **周报**：周期结束日 `range.endDate`（或 period 对应周末）；图例说明「落在周结束日」
   - **月报**：周期结束日 `range.endDate`（月末）
   - **自定义**：优先 `range.endDate`，若单日则 start
5. **交互**：
   - 点击有报告的日期 → 若仅 1 条：直接 `onOpenHistory(entry)` 打开到工作台预览  
   - 若多条：弹出轻量列表（标题 / 类型 / 时间），再选中打开  
   - 点击无报告日期：**弹出轻量操作**（非阻断）
     - 文案：该日暂无报告
     - 操作：「生成日报」→ 以该日为日报目标日触发生成
     - 操作：「空白日补写」→ 打开补写弹窗且目标日=该日（未配置 AI 时按钮禁用 + title「请先配置 AI」）
     - 取消/关闭即可
6. **图例**：说明颜色与类型，并与提交热力图语义区分（报告产出 ≠ 提交活跃）。
7. **数据前置：报告历史设置（MVP 必做）**：
   - 设置中新增「报告历史」区块（或并入已有「报告与历史」说明区）
   - **保留最近 N 条**：可选 `30 / 60 / 120 / 200`，默认 **120**
   - **清空全部历史**：二次确认后清空；与现有工作台清空同一数据源
   - 超出上限时丢弃最旧记录（保持现有切片语义）
   - 日历仅读本地历史，不新增服务端
8. **空态**：无任何历史时，展示引导「生成报告后将显示在此」。

### Out of Scope（MVP）

- 云同步、多设备、团队共享  
- 与提交热力图像素级叠加为同一张图  
- 单条删除、按类型筛选保留、按天/月自动过期  
- 关闭「自动写入历史」开关（二期可选）  
- 年视图、议程列表主视图  
- 导出日历 ICS / 历史归档到磁盘  

## Requirements

1. **R0 报告历史设置**  
   在设置中提供「保留最近 N 条」（30/60/120/200，默认 120）与「清空全部历史」（二次确认）。偏好持久化到本机设置；清空与写入切片均遵守当前 N。

2. **R1 洞察接入**  
   `InsightsView` 在提交热力图正下方增加报告日历通栏；由上层传入 `reportHistory` 与打开/生成/补写回调。

3. **R2 月历渲染**  
   按月展示日期格；标记当日有报告；支持月份切换。

4. **R3 类型区分**  
   至少区分：日报、补写草稿、周报、月报、自定义（可用颜色/缩写点）。

5. **R4 打开报告**  
   单击有报告的日期 → 单条直开 / 多条先选后开；打开后行为与侧栏历史一致（含补写标记恢复逻辑若已有）。

5b. **R4b 空日快捷**  
   单击无报告的日期 → 展示「该日暂无报告」+「生成日报」「空白日补写」；生成日报将该日设为日报日期并走现有提取；补写打开现有弹窗并预填目标日。

6. **R5 历史上限生效**  
   所有 `save`/`load` 路径使用用户配置的 N，不再写死 30；改小 N 时立即裁剪内存与持久化列表。

7. **R6 可访问与主题**  
   支持明暗色；键盘可聚焦日期格（至少 tab + enter）；中文 UI。

## Acceptance Criteria

- [ ] AC0：设置中可选择保留 30/60/120/200 条，默认 120；修改后新生成与已有列表均遵守该上限。
- [ ] AC0b：设置中清空历史需二次确认，确认后最近列表与报告日历同时变空。
- [ ] AC1：洞察页可见「报告日历」区块，不遮挡现有热力图/节奏/趋势主路径。
- [ ] AC2：切换月份可正确显示该月内历史报告落点。
- [ ] AC3：日报与空白日补写在视觉上可区分。
- [ ] AC4：点击单条落点可打开对应历史报告到工作台。
- [ ] AC5：同日多条时需先选择再打开，不静默只开一条。
- [ ] AC6：无历史时有明确空态，不报错。
- [ ] AC6b：点击无报告日期可看到快捷「生成日报 / 空白日补写」；生成日报以该日为目标；补写打开弹窗目标日正确；未配置 AI 时补写禁用。
- [ ] AC7：从旧版 30 条上限升级后数据可加载；用户改小 N 后列表被裁到 N。
- [ ] AC8：暗色模式下图例与格子对比度可读。

## Technical Notes（详设见 design.md）

- 设置：`AppSettings` 增加 `reportHistoryLimit`（number 联合类型 30|60|120|200）；`SettingsDialog` 报告相关分区展示。  
- 历史读写：`load/saveReportHistory` 使用配置的 limit，不再依赖单一模块常量硬编码。  
- 前端组件建议：`ReportCalendar.tsx` + 样式；挂入 `InsightsView`。  
- 数据：`ReportHistoryEntry[]` 纯派生，按 anchor day 聚合 `Map<date, entries[]>`。  
- 补写识别：与现有一致 — `title.startsWith("空白日补写")` 或 `periodLabel.includes("补写草稿")`。  
- Workbench 需把 `reportHistory`、`onOpenHistory` 传入 InsightsView。  
- 不必新增 Rust command。
