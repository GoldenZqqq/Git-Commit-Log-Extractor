# 增加隐私安全的支持诊断包

## Goal

生成脱敏诊断包并提供低摩擦 GitHub Issue 反馈入口

## Requirements

- R1：应用可生成用户确认后导出的脱敏诊断包，默认不上传。
- R2：诊断包包含版本、平台、Git、工作区健康摘要、失败步骤和近期应用日志，但不包含 API Key、OAuth token、代理密码、原始 commit 内容或绝对私有路径。
- R3：提供预览、复制摘要和打开 GitHub Issue 的低摩擦入口。
- R4：无网络时仍可保存诊断包。

## Acceptance Criteria

- [ ] AC1：敏感字段和路径脱敏有 Rust/前端自动化测试。
- [ ] AC2：用户能在导出前查看包含范围并主动确认。
- [ ] AC3：Issue 链接只携带安全摘要，不自动附加本地文件。
- [ ] AC4：失败和离线路径有可读提示。

## Dependency

- 依赖性能基线任务，复用稳定的健康与耗时摘要口径。
