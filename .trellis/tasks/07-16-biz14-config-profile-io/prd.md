# BIZ-14 配置方案导入导出

## Goal

支持导出和导入脱敏的 GitPulse 配置方案，让团队或多设备复用作者别名、项目映射、证据链接和报告模板。

## Requirements

- 定义带 schemaVersion 的配置包，只包含允许共享的字段。
- 永不导出 API Key、OAuth token、代理密码、绝对工作区路径和报告历史正文。
- 导入前展示内容摘要与冲突策略，用户可选择合并或替换可共享配置。
- 对未知版本、非法字段和损坏 JSON 给出明确错误，不污染现有设置。

## Acceptance Criteria

- [ ] 导出文件包含映射、别名、证据规则和模板，不含任何密钥或本机敏感路径。
- [ ] 导入支持预览、合并与替换，取消不修改设置。
- [ ] 同版本往返保持可共享配置一致；旧/未知版本有明确处理。
- [ ] 安全字段白名单和 Playwright 导入导出路径有测试。

## Evidence

- 当前仅支持项目映射 Excel 导入/模板导出；`settingsForPersistence` 不是用户可共享配置协议。
